# Large projects

Larger investigations apply several reinforcement learning algorithms to the same task or complex environment. Each project should explain the methods, compare their behavior under a documented evaluation protocol, and connect the results to the theory.

## Planned project: Rainbow

The [Rainbow reproduction and follow-up investigations](rainbow/) project will build on [basic DQN](../miniProject_01_dqn/) and [DQN variants and replay buffers](../miniProject_02_dqn_variants/). Its goals are to implement Rainbow's six improvements, study the combined agent and ablations, and investigate selected later findings. See its [literature notes](rainbow/literature.md) for initial research leads.

## Adding future projects

Start by copying [project_template](project_template/) into a descriptively named folder here. Add the new project to the [portfolio index](../README.md).

A completed project should include:

- A clear task definition and comparison questions.
- Theory explanations for each algorithm.
- Implementations that share environment handling and evaluation where practical.
- Reproducible experiments with documented budgets, tuning, and seeds.
- Comparative results, limitations, and conclusions about when each method is useful.

No large projects have been implemented yet.
